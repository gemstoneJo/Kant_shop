# Shop 실습

## 실행 방법
1, 2, 3, 4를 눌러 상품목록, 장바구니 추가, 장바구니 삭제, 현재 장바구니에 담긴 상품 리스트를 확인 할 수 있다.
q를 누르면 종료한다.

## 구현한 기능
- 상품 목록 조회: 상품명, 가격, 재고 확인

- 장바구니 담기: 상품 번호와 수량을 입력하여 상품 추가

- 재고 확인: 재고가 부족하거나 품절된 상품의 추가 방지

- 장바구니 빼기: 원하는 상품의 수량을 선택하여 차감

- 장바구니 조회: 상품별 수량, 금액 및 전체 상품 합계 출력

- 메뉴 선택 및 종료: 번호를 통한 기능 실행 및 q 입력으로 종료
